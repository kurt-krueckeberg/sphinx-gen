Create a program will create new MyST Markdown files with the extension of
`.md`. It must NEVER overwrite, truncate, rename, delete, or modify any
existing Myst Markdown file.

The program is configuration driven. A configuration file named
config.yml contains the input to build the output MyST markdown files with
the ".md" extension.

The program will read the YAML file config.yml file that is located
in ~/temp/sphinx-gen/code.

It will also read the template.md file into a variable. It will then alter
this variable by replacing specially designated variables with values found
in the config.yml. This is how it will do this.

There are three types of variables in the template.md: those that start with
"%", those that start will "@", and those that start with "&". 
Here is a list of all the variables:

- %image-no
- &file-name
- @volume
- %image-no 
- %literal
- %trans
- %url 
- %vdate
- @path
- @parish
- @volume-name
- @total-images

All these variables correspond to keys in the config.yml, except for
&file-name, which is the name of the markdown file currently being created.

Using PHP as the example programming language, if the config.yml file was read into an
in-memory array named, say, `$data`, these variables that begin with "@" 

- @volume
- @path
- @parish
- @volume-name
- @total-images

would be replaced with the values of these keys in the config.yml file as
shown in the markdown table below:  

| Variable | Replacement Values |
|----------|--------------------|
| @volume | volume: |
| @path | path: |
| @parish | parish: |
| @volume-name | volume-name: |
| @total-images | total-images: |
